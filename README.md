# 📚 Controle de Faltas V2

Sistema desenvolvido em **Python** para gerenciar faltas de disciplinas utilizando **SQLite** como banco de dados.

## Funcionalidades

* Cadastro de matérias
* Registro de faltas
* Alteração de dados das matérias
* Listagem das matérias cadastradas
* Exclusão de matérias
* Persistência dos dados com SQLite

## Tecnologias

* Python 3
* SQLite3
* Rich

## Como executar

1. Clone o repositório.
2. Instale as dependências:

```bash
pip install -r requirements.txt
```

3. Execute o programa:

```bash
python main.py
```
